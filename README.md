# SVG作品の受付・展示プラグイン

WordPressでSVGアニメーションを受け付け、管理者が内容と動きを確認してから公開する仕組みです。作品一覧、版の管理、一括承認、隔離した再生画面を備えます。

元の3D・SVG販売企画のうち、独立して導入できるSVG部分だけを収録しています。3Dモデル、販売・決済、本番の作品、投稿用の認証情報は含みません。

## 導入

PHP 8系のWordPress環境を用意し、`olerant-svg-gallery` を `wp-content/plugins/` へコピーしてください。管理画面で「Olerant SVG Animation Gallery」を有効にし、固定ページへ `[olerant_svg_gallery]` を置くと一覧を表示できます。作品の受付・確認は管理画面のSVGメニューから行います。導入直後は空の一覧です。

## 状態と制限

実サービスで利用した版0.1.3を元にしています。公開作品上限5,000件、一括確認上限50件です。信頼できる制作者からの作品を管理者が確認して使う設計で、任意の第三者コードが安全であることを保証する仕組みではありません。公開コピーでの新しい動作試験はしていません。

## 利用条件

独自プログラムはルートのMITライセンスです。AcornとGSAPは `olerant-svg-gallery/vendor/` の元の利用条件・著作権表示を保持しています。`ASSET-LICENSE-ja.txt` は作品を配布する際の既定条件で、プログラムのMITとは別です。本リポジトリには既存の配布作品を収録していません。
